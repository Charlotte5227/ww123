辞書は現在 942 項目。v2で不足していたC3時間関係・時間帯・期限、C5条件体系、時間/雨/聴覚系語根を追加しています。

GitHub Pagesでは `public/` の中身をそのまま公開してください。APIキーはAI設定画面から入力し、保存を有効にした場合のみlocalStorageへ保持します。

## v5.5 — Typed IR / deterministic compiler
翻訳アーキテクチャを変更しました。

1. AIは日本語の意味解析だけを行う。
2. 辞書候補を照合する。
3. unresolved があれば辞書全体を意味語で再検索する。
4. AIは表面形ではなく Typed IR を作る。
5. 同一語へ吸収する副語根には relation_id を必須化する。
6. JavaScriptが辞書IDから表面形を決定論的にコンパイルする。
7. AIは完成したfumezuaq表面形を書き換えられない。
8. 独立塊間の必要関係が表現できない場合は unresolved_relation とする。「文脈で分かる」で穴埋めしない。

これにより、辞書にない形の新造、接辞意味の勝手な拡張、語根を無関係に連結する挙動を構造的に抑制します。


## v5.5 — 階層型AIプロンプト指示
重要: これはfumezuaqの言語仕様ではありません。既存仕様をAIが翻訳処理で扱うための運用プロンプトです。

- A: 最上位運用原則
- B: 意味解析・意味塊
- C: 語内部構造の扱い
- D: 意味塊間構造
- E: 辞書利用
- F: Typed IR
- H: 検証・失敗時処理
- I: 禁止する誤推論
- J: 標準判断順序

工程別に必要な章だけを渡す方式へ変更しました。
意味解析AIには意味塊判断を優先させ、辞書照合AIには辞書照合以外をさせず、IR AIには表面形を生成させません。
「吸収可能なら吸収する」ではなく、独立した自然な意味単位なら分離を第一候補とする運用です。


## v5.5 — Human-in-the-loop 意味塊 + 独立プロンプト

### 意味塊モード
1. AI自動
2. AI提案 → ユーザー編集
3. 完全手動

手動/編集モードでは、確定した意味塊の個数・順序・文字列をAIが再分割・再結合することを禁止します。
AIはその後の各塊内部の意味解析、辞書照合、Typed IR、塊間linkだけを担当します。

### プロンプト独立化
AI指示は `public/prompts.js` に分離しました。
今後、プロンプトだけを調整する場合は原則このファイルだけを変更すればよく、`app.js` 本体の改修は不要です。

重要: `prompts.js` はfumezuaqの言語仕様書ではありません。既存仕様・辞書をAIが扱うための運用プロンプトです。


## v5.5 — 固定意味塊の消失防止
- ユーザー固定の意味塊は、未解決でも出力スロットを保持します。
- 未解決チャンクは `〔未解決:原文〕` として可視化され、無言で消えません。
- `surface_required=false` はリンク標識の表面明示要否だけに使い、意味塊削除の根拠にしません。
- 一人称/単数/意図動作主について、辞書に既存IDがある場合のみ再救済候補としてIRへ渡します。
- 「昨日」未解決を「近過去」で補うような unresolved 非波及もプロンプトへ追加しました。


## v5.5 — 分析的構成
辞書完全一致がない概念を即 unresolved にせず、既存の語根・接辞・数詞・Xスコープだけで構成できるかを先に検査します。

確定例:
- 昨日 = 日 + 前 + 1
- 明日 = 日 + 後 + 1
- 明後日 = 日 + 後 + 2
- 3日前 = 日 + 前 + 3

専用の「昨日」語根は要求しません。複合数を語内部へ埋め込む場合は、既存Xスコープ規則を利用します。
辞書衝突・不足がある構成要素は勝手に選ばず、その部分だけ unresolved に残します。


## v5.5 — Unknown可視化・固定チャンク厳守

- 手動/AI提案後編集で固定した意味塊は、1入力スロット = 1出力スロットとして必ず保持。
- 不明部分は `Unknown:<概念>` として表面に残す。既知部分だけを捨てない。
- 「昨日」のような分析的構成は、完全一致辞書がなくても `日 + 前 + 1` に分解する。
  - 現辞書で「日」が未確定なら、その部分だけ `Unknown:日`。
  - `基準より前` と数詞1は既存要素を利用する。
- 固定チャンクモードでは旧 ORPHAN_GOAL / ORPHAN_RAIN の再吸収強制検査を停止。
- 説明AIへ実際の Typed IR (`_debug.ir`) を渡すよう修正。
- `surface_required=false` をチャンク削除の根拠にする説明を禁止。
- K7肯定を単なる肯定文に自動付加しない、過去形から完了相を自動確定しない等をプロンプトへ追加。

- 0–B: noq / raq / teq / kiq / suq / maq / weq / poq / duq / geq / fiq / yoq

複数完成数詞からなる複合数は原則として独立意味塊化し、語内部に埋め込む場合は既存Xスコープを使います。

## v5.5 — 時間単位接頭要素

正式追加:
- 年 `jua-`
- 月 `shae-`
- 半月 `chou-`
- 日 `yai-`
- 時間 `hie-`
- 分 `fou-`
- 秒 `jiu-`

構造:
`TIME_UNIT_PREFIX + SINGLE_COMPLETED_NUMERAL_MORPHEME`

例:
- `hie-teriq` = (20)₁₂時間
- `yai-raq` = 1日
- `jiu-teq` = 2秒

絶対制約:
時間量に使える数は、必ず「単一の完成数詞形態素」1個だけ。
複数の完成数詞形態素からなる数は時間量に使用できない。
Xスコープ、分割、無空白連結、その他の回避策も禁止。例外なし。
